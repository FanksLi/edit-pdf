# Proposal: PDF 文字编辑系统

## 背景

用户需要一个 Web 应用来编辑 PDF 文件中的文字内容。现有 PDF 编辑工具通常：
- 需要安装桌面软件（如 Acrobat）
- 编辑体验不够直观
- 无法精确定位和修改单个小文字块

## 目标

构建一个 Web 应用，实现：
1. PDF 文字的精确提取（逐词级别坐标）
2. 前端渲染为独立的可编辑 DOM 输入框（类似 Figma）
3. 双击文字进入编辑模式，修改后实时更新
4. 生成修改后的新 PDF 文件

## 成功标准

- [ ] 用户可上传 PDF 并看到渲染的页面
- [ ] 文字坐标精确匹配，覆盖层与 PDF 文字对齐
- [ ] 双击可编辑文字，Enter 保存，Escape 取消
- [ ] 导出的 PDF 文字已被正确修改
- [ ] 原始 PDF 文件未被修改

## 不做会怎样

- 用户需要使用传统 PDF 编辑软件，体验不佳
- 无法快速修改 PDF 中的小错误（如错别字、日期等）

## 范围边界

### MVP 范围（本次实现）
- 单页 PDF 编辑
- 文字精确坐标提取
- 双击编辑 + 保存
- 导出修改后的 PDF

### 不在本次范围
- 多页 PDF 切换和批量编辑
- 图片/表格编辑
- OCR 扫描版 PDF 支持
- 精确字体匹配

## 技术决策概览

| 决策项 | 选择 | 原因 |
|---|---|---|
| 后端 PDF 处理 | PyMuPDF (fitz) | 一个库搞定提取+渲染+修改 |
| 前端框架 | React + Vite | 快速开发，良好生态 |
| 前端样式 | Tailwind CSS | 用户偏好，原子化高效 |
| 包管理 | uv | 极快依赖安装 |
| 字体策略 | Helvetica 默认替代 | 简化实现，后续可扩展 |
